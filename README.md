# Bon voyage

A four-page travel discovery and trip-planning website built with HTML5, CSS3, and vanilla JavaScript. It uses `localStorage` to retain bucket-list and trip-plan data in the browser.

## Run locally

1. Open this folder in Visual Studio Code.
2. Install the **Live Server** extension, then right-click `index.html` and choose **Open with Live Server**. Alternatively, open `index.html` directly in a browser.
3. Test all four pages: searching and filtering destinations, saving a favorite, marking it visited, and creating a trip plan.

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `somewhere-travel`.
2. Upload all files in this folder, or run `git init`, `git add .`, `git commit -m "Initial Bon voyage website"`, add the GitHub remote, and push to `main`.
3. On GitHub, open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. Wait for the deployment message, open the supplied site URL, and test links, images, saved destinations, and the trip form on the published site.

The site has not been published by this project; the steps above prepare it for GitHub Pages.
